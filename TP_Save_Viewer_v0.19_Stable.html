Install Car 1 / Car 2 swaps the selected warehouse part onto that car and returns the previously fitted physical copy to warehouse stock. Engine installation changes only the selected engine-unit reference because engines use a shared seasonal pool; engine duplication remains disabled. Duplicate creates a new 100% warehouse copy with a new item ID and no usage tag. In Production rows come directly from the save's Factory queue. Estimated completion week assumes the current assigned production staff remains unchanged and uses remaining factory work ÷ assigned staff; jobs with no assigned staff show no ETA. Fuel is omitted from the Warehouse view. Understanding is shown as a percentage calculated from the save's accumulated understanding laps and the part-specific thresholds from car_parts.json.
Projects
Start uses the project's stored created_week when available. Complete shows the recorded finish week for completed projects, or an estimated finish week for ongoing design-phase projects calculated from stored design duration/progress and the current staff-to-baseline-staff ratio. Completed projects generally do not preserve their original start week in a single current save, so those cells are shown as unavailable rather than inferred. Performance changes and Lap delta use the exact stored project/design projection when available; if an ongoing concept has not generated a projection yet, those cells are left neutral. Ongoing projects preserve both the chosen budget and current spend. Completed chassis designs often preserve the chosen project budget, but completed aero-history entries generally do not preserve their original project spend, so those cells remain unavailable instead of being inferred. The Summary view centralizes season-to-date cumulative development gains and team development-finance information. When Engine is selected, team selection is disabled and all team plus external-supplier engine projects are shown automatically.
